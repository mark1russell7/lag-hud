An add-on for lag

A live HUD of the main thread

The dark panel in the window is the real display of lag-hud. The lag monitors measure this tab, and the panel shows their values. Block the main thread with a button. Then the values change.

The monitors operate. Select a button to block the main thread.

Update rate

The same values, as a chart

snapshot() of the HUD meter gives these values. The scale is logarithmic, from 0.1 ms to 2 s. The line marks 50 ms, the limit of a long task.

Values of 50 ms or more

fanOutMeter gives each value to three meters: the HUD, the meter of all metrics and this list. The list shows each value of 50 ms or more, at the time that lag records it.

  1. No value of 50 ms or more yet.

All the metrics of lag

A second HUD meter gets all 43 metrics. lagHudText gives its text. The HUD in the window shows only six of them, under short names. 


          

        

      


      

        

          
Use it

          

            The package has one display. It uses only the DOM, so it works in a page of each framework. These samples mount it in the life cycle of
            each framework.
          

        

        

          
npm install @mark1russell7/lag-hud @mark1russell7/lag
